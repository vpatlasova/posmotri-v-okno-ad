# Посмотри в окно

Проектная работа второго спринта Яндекс Практикума — приложение для просмотра
видео с видами из окон разных городов. Можно искать ролики по названию города,
выбирать время суток, переключать видео и подгружать дополнительные результаты.

## Ссылка на проект

[Репозиторий проекта на GitHub](https://github.com/vpatlasova/posmotri-v-okno-ad)

## Технологии

- HTML5 и семантическая разметка.
- CSS: Flexbox, локальные шрифты, псевдоклассы и псевдоэлементы.
- Кастомные чекбоксы и состояния интерактивных элементов, включая фокус клавиатуры.
- JavaScript и Fetch API для поиска и загрузки видео.

## Выполненная работа

В `styles/style.css` реализовано оформление по макету: сетка страницы,
видеоплеер, прокручиваемый список карточек, форма поиска и состояния элементов.
Готовые HTML-разметка, JavaScript, шрифты, прелоадеры и сообщения об ошибках
сохранены из стартового проекта.

## Локальный запуск

Из корня репозитория запустите статический сервер:

```bash
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) в браузере.
Для загрузки видео требуется доступ к внешнему API проекта.
Установка зависимостей и сборка не нужны.
